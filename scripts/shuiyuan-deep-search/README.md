# 水源深度搜索助手

Shuiyuan Deep Search 会把一个问题拆成多组站内检索，精读相关水源主题，并生成可追溯到原帖的结构化报告。报告生成后，可以在同一证据范围内继续追问。

## 功能

- 把自然语言问题拆成 3–6 个互补的 Discourse 检索式。
- 最多并行执行 4 个站内搜索、3 个主题读取，自动去重并排序。
- 分页精读候选主题；默认最多读取 8 个主题、每个主题 30 条帖子。
- 首轮阅读后检查证据缺口；资料不足时最多追加 2 个检索式并补读主题。
- 生成摘要、分项结论、证据限制和后续问题，每条引用均链接原主题。
- 在报告下继续对话；追问只使用本轮报告和已读取的来源片段。
- 显示逐阶段进度，支持中止尚未完成的水源和 LLM 请求。
- 界面运行在隔离的 Shadow DOM 中，不修改水源的页面样式和控件状态。
- 自动跳过能够识别出的 Discourse 私信主题。

脚本仅运行于：

```text
https://shuiyuan.sjtu.edu.cn/*
```

## 安装与配置

1. 安装 Tampermonkey 或 Violentmonkey 等用户脚本管理器。
2. 从 GreasyFork 安装本脚本。
3. 登录水源，点击页面右下角“深度搜索”。首次打开且没有 API Key 时会自动进入设置页。
4. 点击页头“设置”或问题框旁的“配置 LLM”，选择服务商并填写对应的 API Key 和模型名称。默认服务商为 DeepSeek，默认模型为 `deepseek-v4-flash`；也可切换到 OpenAI。
5. 可调整主题数和每个主题读取的帖子数，然后保存。

DeepSeek 和 OpenAI 的 Key 分开保存。API 使用费用由所选服务商账户承担；模型不可用、额度不足或限流时，面板会显示错误。

## 使用

输入问题，点击“开始研究”或按 `Ctrl/⌘ + Enter`。脚本依次规划、搜索、精读、检查证据缺口并生成报告。点击来源可在新标签页查看原主题。

报告完成后，在底部输入追问，或点击建议问题。追问不会重新搜索；需要新证据时请重新开始研究。刷新页面会清空当前报告和对话。

## 隐私与网络请求

脚本在用户脚本管理器的本地存储中分别保存 DeepSeek 和 OpenAI API Key，并保存当前服务商、模型名、最多主题数和每主题最多帖子数。报告和对话仅保存在当前页面内存中。

脚本会发出两类请求：

- 向 `https://shuiyuan.sjtu.edu.cn/search.json` 和主题 JSON 地址发出同源请求，使用浏览器现有登录会话读取当前账户有权查看的内容。
- 依据设置，向 `https://api.deepseek.com/chat/completions` 或 `https://api.openai.com/v1/chat/completions` 发送问题、检索计划、选中主题的作者用户名、日期与正文片段、报告和追问，并在 `Authorization` 请求头中发送所选服务商的 API Key。一次研究只会请求当前选中的服务商。

水源 Cookie、站点密码和其他登录凭据不会发送给 LLM 服务商。帖子正文可能含个人信息；开始研究即表示同意把选中正文发给所选服务商。脚本虽主动排除标记为私信的主题，但请勿用它处理敏感或不宜上传的内容。

## 兼容性与限制

- 需要登录水源、所选服务商的可用 API Key，以及允许跨域请求的用户脚本管理器。
- 依赖 Discourse 的搜索与主题 JSON 结构；站点升级后可能需要更新。
- 搜索结果受索引、当前账号权限和排序影响，不代表社区全部内容。
- 为控制上下文和费用，主题数、帖子数和上传字符数均有限；很长主题的后部内容可能未进入报告。
- 模型可能遗漏或误解帖子。重要决定请沿引用阅读原帖核查。
- 首次发布前仍需在已登录的水源页面用目标用户脚本管理器完成手工冒烟测试。
