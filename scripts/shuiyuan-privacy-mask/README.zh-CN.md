# 水源隐私遮罩

[English](README.md) | 简体中文

水源隐私遮罩仅隐藏水源私有账户区域中的当前登录身份，同时保留公开讨论所需的身份语境。它适用于截图、屏幕共享以及在公共场所浏览水源。

## 功能

- 仅在水源运行：

```text
https://shuiyuan.sjtu.edu.cn/*
```

- 将页头中的当前账户头像替换为中性占位符。
- 在当前登录用户自己的个人主页头部隐藏头像、用户名和显示名称。
- 在 Discourse 渲染页面前安装遮罩，避免启动时短暂显示原始身份。
- 有意保留帖子作者、主题参与者、提及、用户卡片等公开身份信息。
- 在水源侧边栏的键盘快捷键按钮旁添加隐私遮罩开关。
- 找不到侧边栏底部时使用小型悬浮按钮作为备用入口。
- 在用户脚本存储中保存启用状态。

## 安装

1. 安装用户脚本管理器，例如 Tampermonkey。
2. [从 GreasyFork 安装本脚本](https://greasyfork.org/scripts/591032-shuiyuan-privacy-mask)。
3. 登录并打开水源：

```text
https://shuiyuan.sjtu.edu.cn
```

## 基本使用

点击侧边栏键盘快捷键按钮旁的 **隐私遮罩：开/关** 切换遮罩。脚本默认启用，设置会立即生效并在刷新后保留。

## 识别边界

脚本只接受来自 Discourse 当前用户运行时状态、页头账户头像、**我的帖子**链接，或用户自己个人主页设置链接的身份信息。只有个人主页 URL 中的用户名与已确认的当前登录用户名一致时，才会启用个人主页遮罩。

相同用户名在公开区域中的出现会被有意保留。只隐藏帖子或主题列表中的某一名作者反而会让当前用户的活动显得异常，从而削弱遮罩的目的。

## 隐私与网络请求

脚本不会发起网络请求。

脚本通过用户脚本存储在本地保存启用状态和最后确认的登录用户名。缓存的用户名用于在直接打开自己的个人主页时，于 Discourse 完成渲染前启用遮罩。

## 兼容性与限制

水源可能更新 Discourse 主题或当前账户组件。如果这些稳定账户区域发生变化，相应遮罩可能暂时无法启用，直到脚本得到更新。

本脚本只是视觉隐私辅助工具，不是安全边界；被隐藏的文本仍可能存在于页面 DOM 中。
