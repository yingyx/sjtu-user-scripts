# 交大选课助手+

[English](README.md) | 简体中文

交大选课助手+ 是用于上海交通大学选课页面的用户脚本。它可以标记课程时间冲突、隐藏冲突教学班、跳转选课社区、显示 jCourse 评分，并通过 DeepSeek 或你配置的 OpenAI 兼容 LLM 按需生成课程评价总结。

## 功能概览

- 根据已选课程时间标记冲突教学班，并显示具体冲突课程的课号与名称。
- 可隐藏与已选课程冲突的教学班或课程面板。
- 可把当前课程类型、关键字和高级筛选保存为一键应用的筛选条件。
- 可同源检查“学生修业情况查询”中的通识类别学分缺口，并推荐筛选条件，不保存个人修业记录。
- 允许同时展开多个课程；逐个点击课程标题即可展开或收起，不再自动关闭其他课程。
- 为匹配到的课程添加选课社区链接。
- 在可匹配课程旁显示 jCourse 平均评分。
- 可管理多个 LLM 来源、切换当前来源，并手动生成课程评价总结。
- 支持自定义总结维度，例如是否点名、是否互动、是否考试等。

## 安装

1. 安装用户脚本管理器，例如 Tampermonkey。
2. 从 Greasy Fork 安装本脚本。
3. 打开上海交通大学选课页面：

```text
https://i.sjtu.edu.cn/xsxk/zzxkyzb_cxZzxkYzbIndex.html
```

脚本只会在匹配的交大选课页面运行。

## 基本使用

页面加载完成后，课程搜索区域附近会出现 `交大选课助手+` 工具栏。

工具栏包含：

- `隐藏冲突课程`：隐藏与已选课程时间冲突的教学班或课程。
- `筛选条件`：保存当前筛选、应用或删除已有条件，并查看未满足通识类别的建议。
- `重新扫描`：在搜索课程、展开课程面板、调整已选课程后重新扫描页面。
- `设置`：管理 LLM 来源、API Key、模型、总结维度和隐藏冲突选项。

脚本会读取页面上的已选课程时间，并与当前展示的教学班时间进行比较。冲突状态会直接显示在课程列表中。

## 筛选条件与通识学分建议

先在学校原生选课区域设置课程类型、校区、课程性质、课程归属、有无余量等条件，再打开 `筛选条件`。保存的条件会记录当前课程类型标签、搜索关键字、高级条件和受支持的自定义输入。应用条件时，脚本会重置原生条件、恢复保存值并执行原生查询。保存后的条件也会出现在原生查询与重置条件按钮之间的紧凑下拉框中，尺寸实时跟随原生查询按钮，选中后立即应用并查询；手动点击 `重置条件` 也会在清空条件后自动查询。

打开筛选条件面板时，脚本会向学校站点同源请求“学生修业情况查询”，仅比较“通识核心类模块”下各类别的要求学分、获得学分和豁免学分。对于未满足的类别，脚本会在对应原生选项存在时推荐由“当前校区 + 通识课 + 通识核心课程 + 对应类别 + 有余量”组成的条件。只有点击 `创建条件` 后建议才会保存。

## 选课社区链接与评分

脚本会尝试把选课页面中的课程匹配到 jCourse：

```text
https://course.sjtu.plus
```

匹配成功后，你可能会看到：

- `选课社区 ↗` 链接：在新标签页打开对应的 jCourse 课程页面。
- 课程评分标记：显示 jCourse 平均评分。

jCourse 数据不会在普通扫描时自动请求。只有当你点击选课社区链接或评价总结按钮时，脚本才会请求 jCourse。

## AI 评价总结

脚本内置 DeepSeek，也支持用户添加 OpenAI Chat Completions API 兼容来源。

启用方式：

1. 点击工具栏中的 `设置`。
2. 选择内置 DeepSeek，或添加一个自定义 LLM 来源。
3. 填入 API Key、Chat Completions 地址和模型。
4. 保存设置。
5. 在课程列表中点击 `总结评价`。

脚本不会自动调用 LLM。只有在你点击总结按钮，并且当前来源已配置 API Key 时，才会发送课程评价文本。

单教学班与多教学班使用相同的总结卡片样式，结果都展开在对应教学班下方。如果一门课有多个教学班，每个教学班都会显示独立的 `总结评价` 按钮，并可同时保留和对比多条结果。

## 设置说明

### LLM 来源

DeepSeek 是不可删除的内置来源。你可以新增、编辑或删除自定义来源，并选择其中一个作为当前来源。自定义来源必须兼容 OpenAI Chat Completions API；接口地址须使用 HTTPS，本机 `localhost`/`127.0.0.1` 可使用 HTTP。

每个来源可配置：

- 显示名称
- Chat Completions 地址
- API Key
- 模型 ID

Chat Completions 地址和模型在设置中并排显示。内置 DeepSeek 默认模型为 `deepseek-v4-flash`；模型 ID 由用户直接填写，脚本不会请求或自动获取模型列表。

### jCourse API Key

可选。如果填写，脚本请求 jCourse API 时会通过 Bearer Token 进行认证。

### 总结维度

总结维度用于告诉 AI 从课程评价中提取哪些信息。脚本支持两类维度：

- 是否类：输出“是 / 否 / 未知”，必要时附带简短解释。
- 开放类：输出 20 字以内的短语。

常见维度示例：

- 是否点名
- 是否互动
- 是否考试
- 作业压力
- 给分情况

你可以在设置面板中新增、删除或修改总结维度。维度备注会作为额外要求发送给 AI。

### 隐藏冲突课程

启用后，脚本会隐藏与已选课程时间冲突的教学班或课程面板。你也可以在工具栏中快速切换这个选项。

## 隐私与网络请求

脚本会把设置和缓存保存在用户脚本管理器的本地存储中。

脚本可能请求：

- `i.sjtu.edu.cn`：打开筛选条件面板时，通过学校同源修业情况接口读取当前账号的通识类别学分要求。
- `course.sjtu.plus`：当你点击选课社区链接或评价总结按钮时。
- `api.deepseek.com`：使用内置 DeepSeek 生成总结时。
- 你配置的 LLM 域名：使用该来源生成总结时。

生成总结时，脚本会向当前 LLM 来源发送最多 12 条 jCourse 评价及课程、教师、评分、学期等上下文。API Key、来源配置、筛选条件和缓存保存在用户脚本管理器的本地存储中。修业情况响应仅在内存中处理，不保存姓名、学号、成绩或课程记录。脚本在普通页面扫描过程中不会自动把课程信息发送给任何 LLM。

## 常见问题

如果冲突标记不准确，点击 `重新扫描`。

如果没有出现选课社区链接或评分，可能是课程没有在 jCourse 中匹配到，也可能是课程名、教师或开课院系信息不足。

如果评价总结失败，请检查：

- 当前 LLM 来源的 API Key、接口地址是否正确。
- 选择的模型是否可用，且服务是否兼容 OpenAI Chat Completions API。
- 当前课程是否能匹配到 jCourse。
- 用户脚本管理器是否允许访问脚本声明的外部域名。

如果交大选课系统页面结构更新，脚本可能需要同步更新。

## 非选课时段离线测试

仓库提供 `tests/fixtures/sjtu-course-assistant-plus-page.html`。该页面的课程面板结构通过 CDP 从真实选课页面提取，但所有课程、教师和选课内容都已替换为测试数据，且网络请求已禁用。

在仓库根目录运行 `python -m http.server 8765`，再打开 `http://127.0.0.1:8765/tests/fixtures/sjtu-course-assistant-plus-page.html`，即可加载当前工作区中的用户脚本并测试筛选条件、通识建议、冲突标记、单/多教学班布局和多课程同时展开。设置仅保存在该离线页面自己的 `localStorage` 中。
