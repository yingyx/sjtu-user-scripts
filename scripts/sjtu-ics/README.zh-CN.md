# SJTU 日历同步

[English](README.md) | 简体中文

将教务系统课表、考试安排和交大日历中的日程聚合为标准 ICS 文件，可直接下载，也可发布到 GitHub Gist，供 iPhone、macOS、Google Calendar 等日历客户端通过 URL 订阅。

脚本仅在以下页面运行：

```text
https://i.sjtu.edu.cn/kbcx/xskbcx_cxXskbcxIndex.html*
https://i.sjtu.edu.cn/kwgl/kscx_cxXsksxxIndex.html*
https://calendar.sjtu.edu.cn/ui/calendar*
```

交我办中的日历以 `calendar.sjtu.edu.cn` iframe 加载，因此在交我办日历页面也会显示脚本入口。

## 功能

- 从教务课表的结构化接口读取课程、教师、地点、周次和节次，并在 ICS 中合并为 `RRULE` 周重复规则；不连续周次使用 `EXDATE` 排除。
- 从考试查询接口读取考试日期、起止时间、地点和考试方式。
- 从交大日历读取指定日期范围内启用的个人、会议、课程、共享日历以及校历事件。
- 支持明确的停课和调休规则：`日期=休` 删除当天课程，`日期=周一` 将同一教学周的周一课表移到指定日期，`日期=第3周周五` 可指定原教学周；校历中明确写有“休”“停课”“放假”或“按第X周周X课表上课”的事件也会转换为规则。
- 默认内置[上海交通大学关于2026年放假及调课安排的通知](https://www.sjtu.edu.cn/tg/20251126/217243.html)中的校级安排。
- 跨页面保存在 userscript 管理器中的采集结果，并按标题、日期、地点和接近的起止时间聚合去重；交大日历中的同一日程优先于教务课表数据。
- 检测去重后仍然重叠的非全天日程，在面板中列出冲突，并为相关 ICS 事件写入 `X-SJTU-CONFLICT:TRUE`；脚本不会擅自删除冲突日程。
- 生成带 `Asia/Shanghai` 时区、稳定 UID、UTF-8 折行的 ICS 文件。
- 为已知校区和教学楼简称补全学校名称及官方街道地址，避免地图客户端把“下院”等校内地点解析成外地同名地点。闵行教学楼会输出为连续、便于地图搜索的 POI 名称，例如 `上海交通大学闵行校区下院 412`，并将教室号与楼名分开。
- 创建不公开列出的 GitHub Gist，后续同步更新同一 Gist，并给出稳定订阅地址。
- 支持手动采集、下载、发布，以及打开受支持页面时按最短间隔自动采集和发布。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey 等 userscript 管理器。
2. 从 GreasyFork 安装本脚本。
3. 登录 SJTU 统一身份认证，并打开任一受支持页面。

## 使用

1. 点击页面右下角的“📅 SJTU ICS”。
2. 打开“设置”，填写：
   - GitHub Token：需要 classic personal access token 的 `gist` 权限；Token 只保存在 userscript 管理器中。
   - 学期第一周周一：课表只有“第几周”，必须用该日期换算实际日期。若先在交大日历采集且返回的范围中能识别第一周，脚本会尝试自动填写。
   - 2026 官方规则：默认启用，可取消勾选。适用于学校通知覆盖的学生；医学院及通知中列出的另行安排人群应关闭并填写自己的规则。
   - 调休规则：每行一条 `YYYY-MM-DD=休`、`YYYY-MM-DD=周一` 或 `YYYY-MM-DD=第3周周五`。第二种表示目标日期按其所在教学周的周一课表上课，第三种明确指定原教学周。手动规则优先于校历识别和内置规则。
   - 可选的文件名、日历名、交大日历读取范围和自动同步间隔。
3. 分别打开课表、考试和交大日历页面，点击“采集当前页面”。每次采集只替换当前学期或当前来源对应的缓存，不会清空其他来源。
   - 若要生成调休补课，必须先采集教务课表，因为交大日历接口没有提供足够的信息来凭空还原另一星期几的完整课表。
4. 点击“下载 ICS”得到本地文件；或点击“仅发布已有数据”创建/更新 Gist。
5. 也可点击“采集并同步”，一次完成当前页面采集和 Gist 发布。首次成功会显示订阅地址。
6. 在 iPhone 上进入“设置 → App → 日历 → 日历账户 → 添加账户 → 其他 → 添加已订阅的日历”，粘贴订阅地址。

“自动同步”默认关闭。启用后，脚本只会在受支持页面被打开、Token 已配置且距离上次成功同步超过设定间隔时运行；它不能在浏览器完全关闭时作为后台服务运行。

| 节日 | 放假日期 | 调课日期与课表 |
| --- | --- | --- |
| 元旦 | 1月1日至3日 | 1月4日按 2025-2026 秋季第16周周五课表 |
| 清明节 | 4月4日至6日 | 无 |
| 劳动节 | 5月1日至5日 | 5月9日按 2025-2026 春季第10周周一课表 |
| 端午节 | 6月19日至21日 | 无 |
| 中秋节 | 9月25日至27日 | 无 |
| 国庆节 | 10月1日至7日 | 9月20日按 2026-2027 秋季第3周周五课表；10月10日按第4周周二课表 |

补课规则按教务课表采集时保存的学年、学期、教学周和星期匹配，不会按补课日所在的自然周错误推算。

常见失败状态：

- “登录可能已失效”：重新登录对应 SJTU 页面后重试。
- “请先填写本学期第一周周一”：在设置中补充日期后重新采集课表。
- GitHub 返回 `401`/`403`：检查 Token 是否有效且具有 `gist` 权限。
- 订阅端未立即更新：日历客户端通常会缓存订阅源，刷新间隔由客户端决定。
- Microsoft Calendar 只显示校历全天事件：请安装最新的 `0.1.0` 开发版本，重新发布 Gist，然后删除并重新添加订阅日历，让 Microsoft 丢弃已缓存的无效订阅源。

## 验证生成的 ICS

在仓库根目录运行校验器，目标既可以是下载的文件，也可以是 Gist raw 地址：

```powershell
npm run ics:check -- "sjtu-calendar.ics" --require-timed
npm run ics:check -- "https://gist.githubusercontent.com/<owner>/<gist-id>/raw/sjtu-calendar.ics" --require-timed --expect-summary "一门已知课程名"
```

该命令使用 ICAL.js 按 RFC 5545 解析文件，展开 `RRULE` 并应用 `EXDATE`，然后按分类报告实际生成的定时和全天日程。包含课程的 SJTU 日历必须显示 `PASS`，且 `timed` 计数不为零；可用 `--expect-summary` 验证一门已知课程，并通过 `--from YYYY-MM-DD --to YYYY-MM-DD` 指定学期范围。分类表示跨来源去重后保留下来的来源，因此从交大日历采集到的课程归在 `交大日历` 下也是正常的。它既能发现宽松日历客户端可能静默忽略的错误日期时间，也能发现语法正确、但重复规则没有生成任何可见课程的文件。

## 隐私与网络请求

脚本会读取并在 userscript 管理器存储以下内容：课程/考试/日历标题、时间、地点、教师、课程代码、考试方式、必要备注、来源标识、调休规则、GitHub Token、Gist ID、设置和最近同步时间。脚本不会把姓名、学号、班级、专业等教务接口附带但生成日历不需要的字段写入缓存或 ICS。

网络请求包括：

- 向当前登录的 `i.sjtu.edu.cn` 发送同源 POST 请求，读取课表、节次时间和考试安排。
- 向当前登录的 `calendar.sjtu.edu.cn` 发送同源 GET 请求，读取日历列表和设定日期范围的事件。
- 仅在用户手动发布或明确启用自动同步时，通过 `GM_xmlhttpRequest` 向 `https://api.github.com` 创建或更新 Gist。上传内容是聚合后的 ICS，因此包含所选日程的标题、时间、地点和描述。

新建 Gist 使用 `public: false`，不会出现在公开 Gist 列表，但任何获得 raw 订阅 URL 的人都可以读取其中的日历内容。请像保护私密链接一样保护订阅地址；若泄露，请在 GitHub 删除旧 Gist 并清空脚本中的 Gist ID 后重新创建。Token 以明文形式存在 userscript 管理器的脚本存储中，不会写入本仓库或 ICS。

## 兼容性与限制

- 课表日期依赖正确的“学期第一周周一”；不同学期采集前应更新该设置。
- 节次起止时间来自教务系统当前返回的校区节次表；若实际教学临时调整而教务数据未更新，ICS 也不会自动得知。
- 只有能可靠判断校区时才补全地点；未知地点保持原样，脚本不会杜撰教学楼坐标。
- 定时事件始终输出带秒的 ICS 时间（`YYYYMMDDTHHMMSS`）；即使交大日历接口只返回时和分，也能兼容校验严格的 Microsoft Calendar。
- 自动调休识别刻意保守：除内置的 2026 官方安排外，普通节日名称不会自动视作停课，只有明确的“休/停课/放假/按第X周周X课表上课”标记才会生效。其余情况应填写手动规则。
- 学校通知明确说明黄浦、浦东校区由医学院另行通知，非全日制专业学位研究生和终身教育学院学生也另行安排；这些用户应关闭“2026 官方规则”。
- 重复规则仅合并起止时间、地点和系列标识一致的事件；调休产生的单次课程保持独立事件，避免错误地改变整个系列。
- 交大日历只读取设置中的时间范围，范围以外的事件不会进入本次缓存。
- 跨来源去重允许最多 15 分钟的起止时间差，用于合并教务节次表与交大日历之间的小幅时间偏差；同来源只有起止时间完全相同时才会合并。
- 冲突检测采用半开时间区间，前一事件结束时间等于后一事件开始时间不算冲突；冲突只提示，不自动选择保留项。
- 自动同步依赖打开匹配页面，不是独立后台任务。
- 目标站点接口或 DOM 变化后脚本可能需要更新。
- 发布前仍需在支持的 userscript 管理器中对三个来源和 iPhone 订阅流程进行人工冒烟测试。
